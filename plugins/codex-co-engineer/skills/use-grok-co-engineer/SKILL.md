# Using Grok Co-Engineer

Codex remains reviewer and merge authority. Use the short
[launch path](../delegate-to-co-engineer/references/launch.md) with Grok
selected. Public name: `Using Grok Co-Engineer`.

Several named providers belong in one `$delegate-to-co-engineer` run.
Existing work uses `$chat-with-co-engineer`; raw lifecycle debugging uses
`$control-codex-co-engineer-agents`. Preserve the same run cursor and use
`decision_or_attention` for its aggregate wait.
